6-Module Project Pipeline

Module 1 · Data Loading

Dataset Ingestion & EDA

Loads 50,000 patient records from Kaggle, identifies missing values, duplicates, and initial statistical distributions.

Module 2 · Preprocessing

Cleaning & Encoding

Label encoding, One-Hot dummy encoding, and missing value imputation for categorical clinical variables.

Module 3 · Normalization

Feature Scaling

StandardScaler Z-score normalization and Min-Max scaling on continuous vitals to eliminate feature magnitude bias.

Module 4 · Classification

Supervised ML Models

Compares Logistic Regression, Ridge Classifier, Decision Tree, Random Forest, SVM, KNN, AdaBoost, and Gradient Boosting classifiers.

Module 5 · Evaluation

Model Assessment

Confusion matrix analysis, Precision, Recall, F1-Score, ROC-AUC, and Before vs After comparative benchmarking.

Module 6 · Deployment

Live Inference Engine

Flask web app serving real-time patient risk scores, clinical risk tiers, and intervention advisories via the prediction UI.
