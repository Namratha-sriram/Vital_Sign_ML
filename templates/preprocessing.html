Data Preprocessing & Feature Transformation

Systematic transformation from raw Kaggle hospital encounter records into standardized, model-ready training matrices — Modules 2 and 3 of the VitalSign pipeline.

Module 2 — Encoding & Cleaning

Stage 01 · Cleaning

Missing Value Imputation

Identifies null sentinel flags (? or None) and imputes median values for continuous vitals and modal categories for admission type codes.

Stage 02 · Label Encoding

Ordinal Category Mapping

Deterministic integer mapping for gender, insulin, A1Cresult, and max_glu_serum — preserving ordinal relationships in tree-based classifiers.

Stage 03 · One-Hot Encoding

Nominal Dummy Variables

Converts admission_type_id and admission_source_id into binary indicator columns via pd.get_dummies(..., drop_first=True) to prevent dummy variable trap.

Module 3 — Scaling & Normalization

Min-Max Scaling [0, 1]

Range Normalization

Formula: (X − min) / (max − min). Compresses all continuous vitals to the [0, 1] range. Sensitive to outliers but useful for KNN and neural architectures.

Z-Score Standardization

Unit Normal Scaling (μ=0, σ=1)

Formula: (X − mean) / std. Applied to Heart Rate, Blood Pressure, Glucose, SpO2 via StandardScaler fitted only on training data to prevent data leakage.

Train/Test Split

Stratified Partition (80/20)

50,000 records split with stratify=y so both train and test retain the 23.7% readmission ratio. Scaler fit strictly on train, applied (transformed) on test.
