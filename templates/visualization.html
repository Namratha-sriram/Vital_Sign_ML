M2 — Linear Models (Supervised)

M2 · LINEAR

Logistic Regression

Sigmoid activation on linear combination of features. Estimates log-odds of 30-day readmission. Implemented in VitalSign.

✓ Implemented
M2 · REGULARISATION

Ridge Regression (L2)

Adds L2 penalty λ∑w² to loss to shrink coefficients. Prevents overfitting on correlated vital features.

◈ Covered in M2
M2 · REGULARISATION

Lasso (L1) / Elastic Net

L1 penalty induces sparsity — zeros out unimportant vital features. Elastic Net = L1 + L2 combined.

◈ Covered in M2
M2 · MULTI-CLASS

Multinomial Logistic (Softmax)

Extends binary LR to multi-class via softmax. Applicable to multi-tier risk (Low/Moderate/High/Critical) in VitalSign.

◈ Covered in M2

M3 — Tree-Based Models (Supervised)

M3 · TREE

Decision Tree

Greedy top-down splits using Gini impurity. Depth-pruned (max_depth=6). Transparent clinical split rules. Implemented in VitalSign.

✓ Implemented
M3 · ENSEMBLE

Random Forest

100 bagged trees with feature subsampling. Gini importance ranking. Current benchmark: F1={{ metrics.metrics['Random Forest'].f1_score }}%, AUC={{ metrics.metrics['Random Forest'].roc_auc }}%.

✓ Evaluated
M3 · BOOSTING

AdaBoost

Sequential ensemble where each tree corrects predecessor's errors by reweighting misclassified samples.

◈ Covered in M3
M3 · GRADIENT BOOST

XGBoost / LightGBM

Histogram-based leaf-wise gradient boosting. The modern tabular data champion. Used in Kaggle competitions.

◈ Covered in M3

M4 — Unsupervised Learning

M4 · CLUSTERING

K-Means Clustering

Groups patients into K clusters by minimizing intra-cluster variance. Elbow method selects K. K-Means++ for smarter initialization.

◈ Syllabus M4
M4 · HIERARCHICAL

Agglomerative Clustering

Bottom-up merging with Ward linkage. Dendrogram visualization. No need to specify K in advance.

◈ Syllabus M4
M4 · DENSITY

DBSCAN

Density-based clustering using ε and minPts. Naturally identifies outlier patients. Handles non-convex shapes.

◈ Syllabus M4
M4 · DIMENSION REDUCTION

PCA / t-SNE / UMAP

PCA for linear projection; t-SNE/UMAP for 2D visualization. Applied to 26 vital features for clinical pattern discovery.

◈ Syllabus M4

M5 — Evaluation Methods & M6 — Engineering

M5 · EVALUATION

Cross-Validation

Stratified 5-fold CV applied to all models. Nested CV for hyperparameter search. Learning curves for bias-variance diagnosis.

✓ Implemented
M6 · DEPLOYMENT
